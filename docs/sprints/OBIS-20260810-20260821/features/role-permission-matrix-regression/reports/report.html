  1. BUG-RPM-01 [P0] Edit Member Role 下拉缺少 Owner
    产品 Member → ⋮ → Edit Role → Assign Role 可选：Product Manager、Version Manager、Batch Manager、Member（锁定）、Resource Manager。没有 Owner。AC-01 要求六种产品内角色均可赋予。
    产品：Test Product Negative / 2087023093035761665，目标用户 test_user4@future.com。
  2. BUG-RPM-02 [P0] Factory Add 只能加 Manager，且无 Edit User 切换 Admin/Manager
    Cloud Factory 02（当前用户为 Admin）Member 的 Add 弹窗标题为 Add Factory Manager，仅 Email，无角色选择，无法通过 Add 赋予 Factory Admin。Admin 行菜单仅 Transfer Admin；Manager 行（Factory Cloud 01）仅 Remove。不存在 Edit User。与 AC-03「Add User 或 Edit User 分别设为 Admin 或 Manager」不符。
  3. BUG-RPM-03 [P1] Factory Manager 在 Admin 行仍能看到 Transfer Admin
    Factory Cloud 01 中当前用户 Role=Factory Manager。打开 test_user modified（Role=Admin）行菜单，出现 Transfer Admin（arco-dropdown-option-disabled 置灰）。AC-07 / 用例预期为 不显示，置灰仍算暴露入口。
    本人 Manager 行菜单只有 Remove，该项符合预期。
  4. BUG-RPM-04 [P1] Factory 详情头栏 Admin 与 Member 列表不一致
    Factory Cloud 01（7830380587921411）头栏 Admin 显示 Future Wei_modify 123；Member 列表同一用户为 Factory Manager，Admin 行是 test_user modified。工厂列表页 Admin 列也是 test_user modified。
