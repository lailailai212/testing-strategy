## Story AC

1.（AC-F01-01）用户进入产品详情 Overview 页 Assets 分区时，分区内不渲染模块切换条，分区只呈现 8 张资产汇总卡。

2.（AC-F01-02）用户进入 Create Version 页时，页面顶部不渲染模块切换条。

3.（AC-F01-03）上述两处切换条移除后，其上下相邻内容应正常收拢衔接，不留出无内容的空白区域。

4.（AC-F01-04）Overview 页 Assets 分区渲染后，8 张汇总卡的构成、顺序与每张卡的统计口径应与改动前一致，卡片位置正确。

5.（AC-F01-05）模块切换条移除后，界面不存在任何其他可进入或切换模块层级的入口（含菜单项、下拉项、链接、面包屑层级与可展开区域）。

6.（AC-F01-06）用户进入 Assets 页或 Create Version 页时，分区导航不渲染顶部标题行（改动前显示当前模块名）。

7.（AC-F01-07）标题行移除后，其下各分区索引项应完整渲染，数量与顺序不变，点击可滚动定位到对应分区，激活态随滚动更新。

8.（AC-F01-08）标题行移除后，分区导航整体不留出无内容的空白区域，索引项正常滚动。

9.（AC-F01-09）界面不再存在「当前模块」概念时，Assets 页与 Create Version 页各分区应直接呈现该产品下全部资产（不按模块过滤）；Overview 页 Assets 分区 8 张汇总卡应按整个产品汇总。

10.（AC-F01-10）改按整个产品取数后，汇总卡计数与各分区行集的呈现应与改动前一致（生产环境不存在一产品多模块）。

11.（AC-F01-11）中文与英文界面下，收敛行为一致，均不出现模块切换条与分区导航标题行。

12.（AC-F01-12）后端返回数据仍带模块字段时，界面应忽略该字段，不渲染、不报错、不出提示。

13.（AC-F01-13）任意角色用户进入上述页面时，收敛行为一致，不因角色、权限点或租户不同而出现差异，界面不提供开关。

14.（AC-F01-14）页面首次渲染应直接以收敛后状态呈现，不出现模块切换条或分区导航标题行先显示再消失的闪现。

15.（AC-F01-15）本改动不引入额外接口请求；Overview、Assets、Create Version 首屏加载时间不劣于改动前。
