# 【SE卡片】内容导入 功能测试用例

> 来源：`acceptance.md（同 feature 包）`（含 TP-ID）；脑图：`xmind/（同 feature 包）`  
> 需求：【SE卡片】内容导入（Story #7018567020）  
> 用例数：25（P0 × 17，P1 × 7，P2 × 1；UI × 9，Functional × 11，E2E × 5）  
> UI 参考：SE 卡片区域（Secure Element 标题区 + 表格列 Name / SE profile ID / Update Time / Tag）；**Add Secure Element** 弹窗（**Select Secure Element \*** 下拉，选项双行 **SE name** + **SE id**，底栏 **Cancel** / **Confirm**）  
> 测试 Product 建议：`Product_SE_Import_QA`；Module 建议：**Secure Element** 类型 `Module_SE_01`（未导入 SE）  
> 公共入口：Product → **Assets** Tab → Module Tab 选中 SE Module → **Secure Element** 卡片区域 → 右上方 **添加**  
> 产品规则：本 Story（#655）验收 **SE 导入**流程，与 Story #653 **SE 卡片内容**（展示/删除等）分离；同 Module **同时仅 1 个 SE**（已导入时「添加」置灰）；**删除已导入 SE 后可再次导入**（删除见 #653）；列表由 **PW 实时调用 SEMS**；筛选 **PV 环境 + Active + create authorization**；**下拉仅展示当前用户有 create authorization 的 SE config**（无权限项不出现，非「添加」按钮置灰）  
> 待确认：Test/Production 切换后已导入 SE 行为
