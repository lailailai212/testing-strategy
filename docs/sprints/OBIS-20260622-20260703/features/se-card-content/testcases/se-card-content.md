> 需求：【SE卡片】SE卡片内容说明（Story #7018449332）  
> 用例数：21（P0 × 17，P1 × 3，P2 × 1；UI × 6，Functional × 13，E2E × 2）  
> 入口规则：Product 页 **Assets** Tab → 定位 **Secure Element（SE）** 卡片区域；SE 卡片操作项（active/deactive、删除）在单张 SE 卡片上；Tag 编辑在 SE 卡片 **Tag** 字段区域。  
> 产品规则：name、SE profile ID 来源于 SEMS；SE profile ID 导入后只读；新导入 SE 默认 **active**；Update Time 取导入时间（AC-05）；删除二次确认文案 **Are you sure you want to delete?** / **确定删除该内容？**；Tag 展示与编辑逻辑与平台现有 asset tag 一致（参照 Product Asset Tag 行为）。  
> 说明：本 Story（#653）验收 **已导入 SE 卡片**的展示与操作；**SE 导入**下拉/添加流程见 Story #655。
