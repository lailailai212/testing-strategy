# Story: 【卡片编辑】自定义卡片

**来源**: [飞书项目 User Story #7013241436](https://project.feishu.cn/obis/userstory/detail/7013241436)  
**空间**: OBIS (`obis`)  
**编号**: 603 | **优先级**: Must | **Sprint**: OBIS-20260622-20260703  
**模式**: Large（H-1～H-5 共 12 条 Product Doc AC + 编辑器校验与数量上限，需独立测试点表与 AC 追溯）

## Story AC

1.（AC-01）用户在 Assets **新增卡片**类型列表中，应看到「**自定义**」选项。

2.（AC-02）用户选择「**自定义**」后，应打开**自定义卡片编辑器**。

3.（AC-03）自定义卡片编辑器应提供**卡片名称**输入框。

4.（AC-04）编辑器字段行表每行应包含四列：**Label** / **Type** / **Key** / **Value**。

5.（AC-05）用户可通过 **+ Add New Content** 新增行、通过行右侧 **—** 删除行。

6.（AC-06）**Type** 下拉选项应为已实现类型：**String / Number / Boolean / Key / Certificate / File**（本期不重定义）。

7.（AC-07）保存时**卡片名称**为**必填**；未填写应阻止保存。

8.（AC-08）已添加字段行后，每行 **Label / Type / Key / Value** 四列均为**必填**；缺失时字段**标红**并**阻止保存**。

9.（AC-09）字段行表**可为空**（零行）即可保存，**不要求至少 1 行**。

10.（AC-10）保存成功后，自定义卡片应出现在 Assets，且排在**所有内置卡片之后**，按**创建顺序**排列。

11.（AC-11）保存后的自定义卡片须适用 Story #602（G-1～G-4）的**增删 / 固定位置 / 数据不丢**规则。

12.（AC-12）同一 Module 下自定义卡片最多 **10 张**。
