## 1. 一句话价值

免费版用户自注册进入系统后，Welcome 页要同时解决三件事：


| 问题        | 本轮能力                                  | Story  |
| --------- | ------------------------------------- | ------ |
| 不知道先做什么   | 两个核心场景引导（DAC 签发 / 工厂烧录），按真实数据自动追踪进度   | 003-02 |
| 遇到问题找资料难  | 页头 Docs / Contact Us + 底部四模块资源中心常驻    | 003-03 |
| 文档/工具要能更新 | V1 用预置配置驱动内容（无 CMS 后台），用户侧即时看到最新文档与下载 | 003-04 |


**Demo 叙事线**：注册者登录 → 选场景开跑 → 底部随时查文档/下工具 → 中英文切换证明内容可运营。

## 2. Demo 前准备（必做）



### 2.1 主账号（必须）


| 项      | 要求                                              |
| ------ | ----------------------------------------------- |
| 账号类型   | **自注册** Tenant Admin（注册者本人）                     |
| 套餐     | 个人 **Free Trial**，**未升级**企业版                    |
| 签约     | 账号下**全部** Tenant 均为未签约（保证 **Contact Us** 可见）    |
| 场景状态建议 | 场景 1（DAC）保持 **未开始**（无任何真实证书模板；Demo 证书不算）        |
| 环境     | 提前打开 Welcome 页，确认 Onboarding Guide、底部四卡、页头入口均正常 |




### 2.2 可选对照账号（时间紧可跳过）


| 账号                            | 用来一句话证明             |
| ----------------------------- | ------------------- |
| 同 Tenant 被邀请 Manager / Member | 场景引导**不展示**（仅注册者可见） |
| 运营后台开通的 Tenant Admin          | 场景引导**不展示**         |




### 2.3 环境检查清单

- [ ] Welcome 页可正常打开，无白屏
- [ ] 底部四卡有预置条目（非「暂无内容」）
- [ ] 页头语言入口是**地球图标**下拉（中文 / English），**不要点错成 Switch**
- [ ] 浏览器允许新标签页 / 下载
- [ ] Docs / FAQ / Manual 外链可打开（非 404）
- [ ] 教程视频：若仍是占位视频，Demo 时**只点开说明「有入口」即关**，不要完整播放

## 3. Demo 脚本（按顺序讲）



### Act 0 — 落点（约 30 秒）

1. 用主账号登录，进入 **Welcome**。
2. 口述：这是免费试用用户的「首页驾驶舱」——上半段引导做事，下半段提供帮助与工具。

**验收点（对老板可见）**：页面结构清晰 = 引导区 + 资源中心。

---



### Act 1 — 场景引导与进度（003-02，约 4～5 分钟）★ 主戏



#### 1A. 可见范围（口头 15 秒，可不切账号）

- **只给注册者本人（Tenant Admin）**：被邀请成员、运营开通租户、升级企业版后 → **不展示**。
- 目的：把「第一次价值验证」留给真正需要上手的自注册管理员。



#### 1B. 场景选择（若刚完成 Tour 会弹窗；否则直接看 Welcome 下半区）


| 讲点     | 操作                               | 预期                                                                             |
| ------ | -------------------------------- | ------------------------------------------------------------------------------ |
| 两个场景可选 | 看 Tab / 场景卡片                     | **Matter DAC Certificate**（约 10 min） / **Factory Secure Provisioning**（约 1 hr） |
| 默认选中   | 弹窗场景下                            | 默认选中 DAC，点 **Start Now / 立即开始**                                                |
| 跳过     | 「I'll explore on my own / 我自己探索」 | 关闭弹窗，留在 Welcome                                                                |


**老板话术**：用户不用猜流程——系统给出两条最短价值路径，并标好预计时间。

#### 1C. 场景 1 结构（DAC，重点讲）


| 步骤  | 名称                                                  |
| --- | --------------------------------------------------- |
| 1   | Create Root Certificate Template / 创建根证书模板          |
| 2   | Create Intermediate Certificate Template / 创建中级证书模板 |
| 3   | Create DAC Template / 创建 DAC 模板                     |
| 4   | Issue DAC Certificates / 进行 DAC 证书签发                |


- 状态按钮当前应为 **Start Now / 立即开始**（未开始）。
- 点击 **Start Now** → 跳转该场景**第一步创建页**（可点进去展示入口，再返回 Welcome，不必真签发完）。

**状态判定（口头即可，不必现场造三种状态）**：


| 状态  | 按钮           | 判定（Demo 数据不算）   |
| --- | ------------ | --------------- |
| 未开始 | Start Now    | 无任何证书模板         |
| 进行中 | Continue     | 有模板但未签发真实 DAC   |
| 已完成 | Complete（禁用） | 至少签发过 1 张真实 DAC |


> **现场建议**：只演示「未开始 → Start Now 跳转」。  
> 「Continue 弹窗选 PKI / Product」与「双场景完成自动收起」属增强路径，时间不够可口述。



#### 1D. 场景 2 一笔带过（工厂烧录）

5 步：产品 → 版本 → 批次 → 分配烧录站 → 烧录设备；完成条件 = 至少 1 条真实 Production Record。

**老板话术**：证书合规约 10 分钟可体验；产线烧录约 1 小时，适合想走完闭环的用户。

---



### Act 2 — 页头能力（003-03，约 2 分钟）

停留在 Welcome，指页头右侧：


| 顺序  | 操作                      | 预期 / 话术                                              |
| --- | ----------------------- | ---------------------------------------------------- |
| 1   | 点 **Docs / 文档中心**       | 打开文档站：EN `…/docs/obis`；ZH `…/docs/zh-cn/obis`        |
| 2   | 点 **Contact Us / 联系我们** | **新窗口**打开官网联系页（中文 `/zh/contact-us`，英文 `/contact-us`） |
| 3   | 点 **地球图标** → 切语言        | 下拉含 中文 / English；切换后页头与底部文案即时变                       |
| 4   | （可选）全屏按钮                | 进入/退出全屏                                              |


**老板话术**：文档与联系销售始终在顶栏可达；Contact Us 仅对「账号下全是未签约租户」展示——签约客户不再打扰。

---



### Act 3 — 底部资源中心 + 内容生效（003-03 + 003-04，约 3～4 分钟）

滚动到 Welcome **底部**四张等宽卡片：


| 模块                       | Demo 动作     | 预期                     |
| ------------------------ | ----------- | ---------------------- |
| Quick Start / 快速入门       | 点列表**一条**   | 新标签打开文档详情（可访问）         |
| Quick Start              | 点卡片**头部**   | 新标签打开文档列表页             |
| Operations Manual / 操作手册 | 点任一条        | 新标签打开对应概述文档            |
| FAQ / 常见问题               | 点任一条        | 新标签打开 FAQ              |
| Tools & Downloads / 工具下载 | 点卡片**头部**   | 打开**右侧 Drawer**（不是新标签） |
| Tools & Downloads        | Drawer 内点下载 | **直接下载**，无详情页          |


**003-04 要讲清的一句话（不必进后台）**：

> V1 **没有** Operator CMS 界面；内容由产品侧按「分类 → 内容项」模型预置配置。  
> 用户侧看到的四卡标题、条目、外链、下载项，就是这套模型生效的结果。  
> 后续再建设 CMS，模型已按可运营字段设计好了。

**可选加分（30 秒）**：切换中英文后，再点同一 Quick Start 条目，URL 从 EN 路径变为 `/zh-cn/` 路径——证明内容与语言绑定、可运营。

## 7. 问答备用（简答）

**Q：进度怎么判定？会不会手勾完成？**  
A：按领域真实数据自动判定（真实 DAC / 真实 Production Record）；Demo 预设数据不计入。

**Q：为什么企业版没有场景引导？**  
A：引导服务「首次价值验证」；升级后能力与路径不同，引导区收起，避免干扰正式客户。

**Q：内容以后怎么改、要不要发版？**  
A：V1 产品侧改预置配置即可生效；模型已按分类/内容项/中英文字段设计，后续 CMS 在此之上建设。

**Q：Contact Us 为什么有的账号没有？**  
A：账号只要关联过任一已签约租户，任何租户上下文下都不展示，避免对签约客户重复销售打扰。
