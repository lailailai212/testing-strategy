## 约定

- 一个 feature 只归属一个 Sprint（跨迭代沿用：在后续 Sprint README 链接引用）

- 全局 MeterSphere 模块树：`docs/modules/metersphere-modules.json`
- 根目录 `story/` 仍为飞书导入暂存；正式关联写在各 feature 的 `META.md`
