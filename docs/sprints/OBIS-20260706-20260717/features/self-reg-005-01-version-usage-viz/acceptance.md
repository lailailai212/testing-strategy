# Story: 【自注册】005-01 — 版本展示与用量可视化

**来源**: [飞书项目 User Story #7007364069](https://project.feishu.cn/obis/userstory/detail/7007364069)  
**空间**: OBIS (`obis`)  
**编号**: 586 | **优先级**: Must | **Epic**: OBIS自注册  
**模式**: Large（Welcome / Profile 双入口 + 版本对比弹窗 + 实时用量与 Demo 排除，跨模块且规则 > 10）

---

## Story AC

1.（AC-01）免费版用户进入 Welcome 页面时，欢迎卡片应展示套餐名称/Package Name，并提供升级入口（`Upgrade Plan` / `升级套餐`）。

2.（AC-02）免费版用户进入 Profile 页面时，所属租户名称旁应展示套餐名称/Package Name，且免费版标签可点击进入版本对比详情；企业版标签不可点击。

3.（AC-03）打开版本对比弹窗后，对比表应包含 7 项对比维度：产品数量、单产品最大生产量、KMS 密钥数量、KMS 密钥有效期、PKI 证书模板、PKI 证书有效期、工厂类型。

4.（AC-04）版本对比弹窗免费版列应展示实时用量值，且 Demo 资源不计入限额统计。

5.（AC-05）版本对比弹窗企业版列各维度应展示绿色 ✓ 图标 + 「按合同」/ `Per contract`。

6.（AC-06）版本对比弹窗底部应展示「升级到企业版」/ `Upgrade to Enterprise` 按钮。

7.（AC-07）用户点击「升级到企业版」按钮后，应打开联系销售弹窗。

## 待确认

- [ ] 免费版列「实时用量」各维度的精确展示格式（如 `已用/限额`、仅数字、或与静态文案 `7 / 10` 的合成方式）需与实现/产品最终稿对齐；当前以 Story「展示实时用量值」为准。
- [ ] 企业版列统一为「绿色 ✓ + 按合同」时，需求表中企业版工厂类型文案 `Cloud + On-prem` 是否仍单独展示，或完全被「按合同」替代（TP-CMP-TBL-06）。
- [ ] 单产品最大生产量、KMS/PKI 有效期等维度的「实时用量」是否有可观测的已用值，或仅展示限额文案（Story 强调实时用量，但部分维度可能无「已用」概念）。
- [ ] 免费版下 Manager / Member 是否具备创建真实产品 / KMS 密钥 / PKI 证书模板的权限（TP-CMP-USAGE-09 前置）。
- [x] **企业版切回免费版**：路径在**超管页面**；企业版期间资源**不计入**免费版用量；回退后用量**恢复为升级企业版之前**的用量（2026-07-16 确认）

## Out of Scope

- 企业版用户在 Welcome 欢迎卡片上的套餐标签与升级入口（需求明确不展示）
- 联系销售弹窗本身的交互细节（引用 FT-S-004-05，本 Story 仅要求打开该弹窗）
- 配额触达拦截、升级付费流程、合同签约流程
