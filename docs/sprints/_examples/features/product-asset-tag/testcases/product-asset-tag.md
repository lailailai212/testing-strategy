# Product Asset Tag 功能测试用例

> 来源：`xmind/（同 feature 包）`  
> 需求：Product Asset — Certificate/Key Tag  
> 用例数：16（P0 × 13，P1 × 3）  
> 入口规则：**Assign Security Key** 弹窗 → Product Asset 页 **Keys** 区域点击 **Assign Key**；**Assign Certificate** 弹窗 → Product Asset 页 **Certifications** 区域点击 **Assign Certificate**。  
> 产品规则：google certificate config / matter config 等**系统默认 Tag 仅存在于 Assign Certificate**；Assign Security Key 的 Tag 下拉**无系统默认项**，仅展示产品级自定义 Tag。  
> 用例名称格式：`【{模块 slug}】【功能】{子功能} - {一句话描述}`（模块 slug 由所属模块路径推导，如 `/Cloud/Product/Overview` → `Product-Overview`；禁止 `【Product】【Version】` 等双层模块前缀）  
> 所属模块：对齐 `docs/modules/metersphere-modules.json` 合法路径（Product Asset → `/Cloud/Product/Assets`；Version → `/Cloud/Product/Version`；产品详情 → `/Cloud/Product/Overview`）
