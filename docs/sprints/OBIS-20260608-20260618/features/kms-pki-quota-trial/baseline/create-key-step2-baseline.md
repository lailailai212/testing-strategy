## 页面结构

```text
向导步骤条：Basics ✓ → 2 Generation Method (active) → 3 Permission
表单区 Key Source Setting（Step 2/3）
└── Key Source 单选卡片（5 选 1，必填 keySource）
    ├── Generated by System
    ├── Import Key Pair
    ├── Import PK
    ├── BYOK AK/SK
    └── BYOK Account Role
底栏：[Back]  [Skip]  [Next]
```

## 关键交互元素

| 区域 | 元素 | 说明 | 推荐 Locator（Playwright） | 稳定度 |
|------|------|------|---------------------------|--------|
| 向导 | Step 2 Generation Method | active | `getByText('Generation Method')` | 中 |
| 表单标题 | Key Source Setting | Step 2/3 | `getByRole('heading', { name: 'Key Source Setting' })` | 高 |
| Key Source | Generated by System | 单选卡片 | `getByRole('radio', { name: 'Generated by System' })` 或 `label` filter | 高 |
| Key Source | Import Key Pair | 单选卡片 | `getByRole('radio', { name: 'Import Key Pair' })` | 高 |
| Key Source | Import PK | 单选卡片 | `getByRole('radio', { name: 'Import PK' })` | 高 |
| Key Source | BYOK AK/SK | 单选卡片 | `getByRole('radio', { name: 'BYOK AK/SK' })` | 高 |
| Key Source | BYOK Account Role | 单选卡片 | `getByRole('radio', { name: 'BYOK Account Role' })` | 高 |
| 底栏 | Back | 返回 Step 1 | `getByRole('button', { name: 'Back' })` | 高 |
| 底栏 | Skip | 跳过本步 | `getByRole('button', { name: 'Skip' })` | 高 |
| 底栏 | Next | 进入 Step 3 | `getByRole('button', { name: 'Next' })` | 高 |

## 校验规则（实测）

| 场景 | 行为 |
|------|------|
| 未选 Key Source 点 Next | 展示 `keySource is required.` |
| 选择 Generated by System 后点 Next | 进入 Step 3 Permission |

## 与 Step 1 底栏差异

| Step | 底栏按钮 |
|------|----------|
| Step 1 | Cancel、**Continue** |
| Step 2 | **Back**、**Skip**、**Next** |
| Step 3 | **Complete** |

## Fragile 汇总

- 五个 Key Source 选项为**卡片式 radio**（`label.arco-radio`），建议用文案 filter，避免 nth
- 页面无 `data-testid`
- 各选项旁有说明图标（img），不影响主交互

## 入口路径

`Create Key Step 1` 填完必填项（含 Usage）→ **Continue** → Step 2
