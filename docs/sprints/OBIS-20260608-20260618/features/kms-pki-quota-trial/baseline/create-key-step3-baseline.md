## 与 Step 1/2 底栏差异

Step 3 **无 Back / Next**，仅 **Complete** 单按钮完成创建。

## Fragile 汇总

- Assign Permissions 为复合控件（含 View 标签 + 可扩展权限），需限定在弹窗容器内定位
- `Please Enter` placeholder 与登录页等其他页面可能冲突，弹窗内应加 `getByRole('dialog')` 或标题父级限定
- 行内操作按钮无文案，仅图标

## 入口路径

`Create Key Step 2` 选 Key Source → **Next** → Step 3 → **Complete** 完成创建
