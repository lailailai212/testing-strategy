# 【自注册】004-02 — KMS 与 PKI 配额限制 功能测试用例

> 来源：`acceptance.md（同 feature 包）`（含 TP-ID）；脑图：`xmind/（同 feature 包）`  
> Baseline：`baseline/*-baseline.md`  
> 需求：【自注册】004-02 — KMS 与 PKI 配额限制（自注册免费版）  
> 用例数：36（P0 × 23，P1 × 12，P3 × 1；UI × 5，Functional × 22，E2E × 9）  
> 入口规则：KMS 密钥数量校验 → **KMS Key List** 页点击 **+ Create Key**；KMS 有效期校验 → **Create Key** 向导 **Validity** 字段；PKI 根证书数量校验 → **PKI List** 页点击 **+ Create Root Cert**；PKI 中级/设备证书数量校验 → 对应创建入口（按钮文案待确认）；PKI 有效期校验 → **Create Certificate** 向导 **Validity** 字段。  
> 产品规则：自注册租户 KMS 无预设 default key、PKI 无系统预设数据（AC-08 Out of Scope）；Deleted 状态不计入配额，Active / Revoked / Expired 等均计入（AC-07）；根证书配额按租户下合计统计（跨 Specification）；Unlimited / 无限制 有效期类型隐藏；超限错误提示为 "Trial max validity is 2 years" / "免费版有效年限最长 2 年"；本版本配额触达为简单提示并阻断，无升级引导按钮。
