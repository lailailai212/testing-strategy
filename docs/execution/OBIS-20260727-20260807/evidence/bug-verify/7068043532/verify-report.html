复验步骤

  1. 登录 IoT SIT，打开 Group 详情页并切换到 Audit。
  2. 点击表格工具栏 Columns，打开列配置面板。
  3. 勾选 Operation Detail（原未勾选）。
  4. 拖拽手柄将 Operation Detail 移到 Operation Time 之后。
  5. 点击 Save，核对表头列顺序。

预期 vs 实际

  • 预期：非固定列可自由拖拽；Operation Detail 与 Operation Time 可交换顺序；保存后表格列顺序与面板一致。
  • 实际：拖拽成功，面板顺序变为 Operator → Organization → Operation Type → Operation Time → Operation Detail；Save 后 Audit 表头顺序相同。
