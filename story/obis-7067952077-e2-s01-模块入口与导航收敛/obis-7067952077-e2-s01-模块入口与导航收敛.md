### 1. 用户故事与本期口径

- 作为在产品详情下查看资产的产品成员，希望界面不再要求先选模块再看内容，直接在产品这一层看到全部资产，不必理解从不单独操作的中间层级，也不必在切换模块后才确认看全了该产品的内容。
- **本期口径（PRD §2.3 BR-G-01、BR-G-02）**：只收界面渲染，不动后端。数据仍按模块归属存储，接口仍可返回模块字段，界面忽略即可。改动对全部角色一致生效，**不做任何角色分支、不提供开关**。
- **BR-G-04**：隐藏是「不渲染」，不是「渲染后藏起来」——被隐藏的元素不得出现在任何可由用户勾出、展开或切换到的地方。
- 本 Story 只管两处模块切换条与一处分区导航标题行；取数范围随之改变的口径见 BR-F01-03。

### 2. 模块切换条（CH-03、CH-11）

- 用户进入产品详情 Overview 页 Assets 分区 → 分区内不渲染模块切换条，分区只呈现 8 张资产汇总卡。（AC-F01-01）
- 用户进入 Create Version 页 → 页面顶部不渲染模块切换条。（AC-F01-02）
- 上述两处切换条移除后 → 其上下相邻内容正常收拢衔接，不留出无内容的空白区域。（AC-F01-03）
- Overview 页 Assets 分区渲染后 → 8 张汇总卡的构成、顺序与每张卡的统计口径与改动前一致，卡片位置正确（本期不动汇总卡本身，仅取数范围按 AC-F01-09 变化）。（AC-F01-04）
- 模块切换条移除后 → 界面不存在任何其他可进入或切换模块层级的入口，包括菜单项、下拉项、链接、面包屑层级与可展开区域。（AC-F01-05）

### 3. 分区导航标题行（CH-06）

- 用户进入 Assets 页或 Create Version 页 → 分区导航不渲染顶部标题行（该标题行改动前显示当前模块名）。（AC-F01-06）
- 标题行移除后 → 其下各分区索引项完整渲染，数量与顺序不变，点击可滚动定位到对应分区，激活态随滚动更新，与改动前一致。（AC-F01-07）
- 标题行移除后 → 分区导航整体不留出无内容的空白区域，索引项正常滚动。（AC-F01-08）

### 4. 取数范围（BR-F01-03）

- 界面不再存在「当前模块」这一概念 → Assets 页与 Create Version 页的各分区直接呈现该产品下的全部资产、不按模块过滤；Overview 页 Assets 分区的 8 张汇总卡按整个产品汇总。（AC-F01-09）
- 改按整个产品取数后 → 汇总卡计数与各分区行集的呈现与改动前一致（生产环境不存在一个产品下多个模块的情况，见 BR-F01-04）。（AC-F01-10）

### 5. 一致性与兜底

- 中文与英文界面下 → 上述收敛行为一致，两种语言都不出现模块切换条与分区导航标题行。（AC-F01-11）
- 后端返回的数据仍带模块字段 → 界面忽略该字段，不渲染、不报错、不出提示（PRD §4 E4）。（AC-F01-12）
- 任意角色的用户进入上述页面 → 收敛行为一致，不因角色、权限点或租户不同而出现差异，界面不提供开关（PRD §2.3 BR-G-01）。（AC-F01-13）
- 页面首次渲染 → 直接以收敛后的状态呈现，不出现模块切换条或分区导航标题行先显示、随后再消失的闪现。（AC-F01-14）
- 本改动不引入额外接口请求 → Overview 页、Assets 页与 Create Version 页的首屏加载时间不劣于改动前（PRD §5）。（AC-F01-15）

### 6. 业务规则（BR）

| 编号 | 规则 |
|------|------|
| BR-F01-01 | Overview 页 Assets 分区内与 Create Version 页顶部的模块切换条不再渲染；移除后上下间距正常收拢，不留空白带。（PRD §3.1、§2.1 CH-03 / CH-11） |
| BR-F01-02 | Assets 页与 Create Version 页的分区导航标题行不再渲染；其下各分区索引项的渲染、点击与滚动定位一概不变——只去标题，不去索引。（PRD §3.1、§2.1 CH-06） |
| BR-F01-03 | 界面不再有「当前模块」概念；Assets / Create Version 直接呈现该产品全部资产；Overview 汇总卡按整个产品汇总。 |
| BR-F01-04 | 生产环境不存在一个产品下多个模块；取数改按整个产品后，各分区行集与汇总卡计数与改动前一致，无需为多模块去重或加来源标识。 |
| BR-F01-05 | 8 张资产汇总卡的构成、顺序与统计口径不变；Assets 各分区列集、列序、单元格取值与行菜单不变。本期只改取数范围。 |
| BR-F01-06 | 改动只在界面渲染层；后端接口、数据结构与权限判定不变；接口仍可返回模块字段，界面忽略。 |
| BR-F01-07 | 隐藏是「不渲染」而非「渲染后藏起来」；被隐藏元素不得出现在任何可勾出、展开或切换到的地方。 |
| BR-F01-08 | 改动对全部角色一致生效，不按权限、不按租户区分，不提供开关，无需实现角色分支。 |
| BR-F01-09 | 中文与英文界面都不得出现模块层级内容。 |
| BR-F01-10 | 本期不动 Create Version 页除切换条与分区导航标题行以外的任何部分（「基本信息」字段、其下 7 个分区、字段与表格、按钮与提交流程一律不改）。 |
| BR-F01-11 | 产品详情的页签条本身不动；本期改动都落在页签内部。 |

### 7. 测试要点（来自 Description）

1. **正常流程**：Overview Assets 分区无模块切换条、仅 8 张汇总卡且构成顺序不变；Assets / Create Version 分区导航无标题行、索引项完整可点击滚动定位；Create Version 顶部无模块切换条，其余分区/字段/按钮/提交流程不变。
2. **错误场景**：后端仍返回模块字段时界面忽略、不渲染、不报错、无提示；首屏无切换条或标题行闪现。
3. **边界条件**：整产品取数后汇总卡计数与分区行集与改动前一致；移除后不留空白；无任何进入模块层级的其他入口。
4. **权限校验**：无新增权限点；不同角色与不同租户进入三页呈现一致、无角色分支、无开关。
5. **跨模块联动**：确认后端模块归属数据与接口未改；中英文收敛一致；未引入额外接口请求、首屏加载不劣于改动前。
