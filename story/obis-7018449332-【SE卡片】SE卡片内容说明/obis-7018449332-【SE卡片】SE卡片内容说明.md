## 需求描述（Product Doc）

### 1. 功能概述

- 在 Assets 中增加 **Secure Element（SE）** 卡片，以卡片形式展示。

### 2. SE 卡片展示字段

| 字段 | 说明 |
|------|------|
| name | SE 卡片的名称，从 SEMS 获取；SEMS 若更新该字段，则同步更新 |
| SE profile ID | SE 唯一标识，从 SEMS 获取 |
| active 状态 | 默认 active |
| Update Time | SE 卡片目前不会更新，默认为导入时间；active / deactive 变化将导致 Update Time 变化 |
| Tag | 同平台 tag 的逻辑 |
| 操作项 | active / deactive；删除（需二次确认） |

### 3. 操作项

- **active / deactive**：支持切换 SE 卡片的 active 状态。
- **删除**：需二次确认后执行。
  - 二次确认弹窗文案：`Are you sure you want to delete?` / `确定删除该内容？`

### 4. 验收标准（AC）

- **AC-01**：SE 卡片在 assets 中以卡片形式展示，字段包含：name、SE profile ID、active 状态、Update Time、Tag、操作项。
- **AC-02**：SE profile name 来源于 SEMS；当 SEMS 侧该字段更新时，PW 卡片自动同步为最新值。
- **AC-03**：SE profile ID 来源于 SEMS，作为 SE 唯一标识，导入后只读不可编辑。
- **AC-04**：active 状态默认为 active。
- **AC-05**：Update Time 取导入时间，导入后不再更新。
- **AC-06**：Tag 的展示与编辑逻辑与平台现有 tag 一致。
- **AC-07**：操作项支持 active / deactive 切换。
- **AC-08**：操作项支持删除，删除须二次确认后执行，文案见上文。
