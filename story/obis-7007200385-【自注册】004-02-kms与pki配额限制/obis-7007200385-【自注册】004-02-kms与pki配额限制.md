### 1. User Story

作为免费版用户，我在创建 KMS 密钥或 PKI 证书模板时系统校验配额上限，触达上限时弹出统一引导弹窗，以便我了解免费版的密钥和证书资源限制。

### 2. KMS 配额

| 配额项 | 免费版默认值 | 校验时机 |
|--------|-------------|----------|
| 密钥数量 | ≤ 5 / Tenant | 点击创建密钥时 |
| 密钥有效期 | ≤ 2 年 | 创建/编辑密钥时，实时校验 |

- **不计入配额**：已销毁 / Deleted 状态的密钥
- **自注册租户说明**：无预设 default key，KMS 列表初始为空，配额仅统计用户创建的密钥
- **计入配额**：其余状态（含 Active、Revoked、Expired 等）均计入

**创建密钥交互：**

- 点击「+ Create Key」后，系统校验当前密钥数量：
  - 已达上限（≥ 5）→ 弹出简单提示弹窗并阻断后续操作，不打开创建页面
  - 未达上限 → 打开创建页面
- 创建页面中「Validity / 有效期」字段：
  - 有效期类型 **Unlimited / 无限制** 隐藏，用户不可见（见评论 2026-06-09）
  - 切换按钮：**By Years / 按年限** 和 **By Date / 按日期** 两种模式
  - 按年限模式：数字输入框 + "Years / 年" 单位标签
    - 失焦（onblur）校验：输入值 > 2 时显示错误
    - 错误提示："Trial max validity is 2 years" / "免费版有效年限最长 2 年"
  - 按日期模式：日期选择器
    - 失焦校验：所选日期超过当前时间 + 2 年时显示错误
    - 错误提示："Trial max validity is 2 years" / "免费版有效年限最长 2 年"
  - 点击「Next / 下一步」提交时再次校验有效期，不符合则阻止提交

### 3. PKI 配额

| 配额项 | 免费版默认值 | 校验时机 |
|--------|-------------|----------|
| 根证书 | ≤ 2 / Tenant（**租户下合计**，不按 Specification 分别计数） | 点击「+ Create Root Cert」时 |
| 中级证书 | ≤ 2 / Tenant | 点击创建证书时 |
| 设备证书模板 | ≤ 2 / Tenant | 点击创建证书时 |
| 证书有效期 | ≤ 2 年 | 创建证书时，实时校验（见下方例外场景；本版本不支持编辑证书） |

- **不计入配额**：已销毁 / Deleted 状态的证书模板
- **自注册租户说明**：无系统预设证书模板，PKI 列表初始为空，配额仅统计用户创建的模板

**创建根证书交互：**

- 点击「+ Create Root Cert」后，系统校验当前租户下**所有 Specification**（Matter / Google Cast / Custom）的根证书**合计数量**：
  - 合计已达上限（≥ 2）→ 弹出简单提示弹窗并阻断后续操作，不打开创建页面
  - 未达上限 → 打开创建页面

**创建中级/设备证书交互：**

- 点击对应创建入口后，系统校验该类型证书模板在租户下的合计数量：
  - 已达上限（≥ 2）→ 弹出简单提示弹窗并阻断后续操作，不打开创建页面
  - 未达上限 → 打开创建页面

**创建页面中「Validity / 有效期」字段（适用场景见下方例外）：**
  - 有效期类型 **Unlimited / 无限制** 隐藏，用户不可见（见评论 2026-06-09）
  - 切换按钮：**Years / 按年** 和 **Date / 按日期** 两种模式
  - 按年模式：输入框 placeholder "e.g. 2"
    - 失焦校验：输入值 > 2 时显示错误
    - 错误提示："Trial max validity is 2 years" / "免费版有效年限最长 2 年"
  - 按日期模式：日期选择器
    - 失焦校验：所选日期超过当前时间 + 2 年时显示错误
    - 错误提示："Trial max validity is 2 years" / "免费版有效年限最长 2 年"
  - 点击「Create / 创建」提交时再次校验有效期，不符合则阻止提交

**有效期 2 年限制的例外场景（不受 2 年限制）：**

- 创建非根证书时，若上级证书不包含私钥：不展示有效期字段（根据 CSR 签发定义）
- 创建根证书（上传公钥的方式）：用户不可修改有效期

### 4. 验收标准（来源 Description）

- AC-01: 点击创建密钥时校验密钥数量 ≥ 5，超限弹出简单提示并阻断，不打开创建页面
- AC-02: 创建/编辑密钥时有效期 ≤ 2 年，支持按年限和按日期两种模式
- AC-03: 密钥有效期失焦校验，> 2 年时显示对应错误提示
- AC-04: 点击 Create Certificate 时校验每类模板 ≥ 2，超限弹出简单提示并阻断，不打开创建页面
- AC-05: 创建证书时有效期 ≤ 2 年，支持按年和按日期两种模式（本版本不支持编辑证书）
- AC-06: 证书有效期失焦校验，> 2 年时显示对应错误提示
- AC-07: 仅已销毁 / Deleted 状态的密钥和证书模板不计入配额统计；其余状态（含 Active、Revoked、Expired 等）均计入
- AC-08: Demo 资源不计入配额统计（**自注册租户无 Demo/预设数据，本 Story 不测**）
