## 需求描述（Product Doc）

### H-1 新增自定义卡片入口（P0）

**As** 资产管理员，**I want** 新增卡片时多一个「自定义」选项，**so that** 创建系统未预置的卡片。

**AC**

1. 新增卡片类型列表中含「**自定义**」。
2. 选「自定义」打开 **自定义卡片编辑器**。

### H-2 编辑卡片名与字段行表（P0）

**As** 资产管理员，**I want** 设定卡片名并维护 **Label / Type / Key / Value** 行表，**so that** 定义卡片内容结构与值。

**AC**

1. 编辑器含 **卡片名称** 输入。
2. 字段行表每行四列：**Label** / **Type** / **Key** / **Value**。
3. **+ Add New Content** 新增行；每行右侧 **—** 删除行。
4. **Type** 下拉沿用已实现选项（**String / Number / Boolean / Key / Certificate / File**），本期不重定义。

### H-3 编辑器校验（P0）

**As** 资产管理员，**I want** 保存前被强制填全字段，**so that** 卡片数据完整可用。

**AC**

1. **卡片名称** 必填。
2. 添加了行后，每行 **Label / Type / Key / Value** 四列均必填；缺失 **标红** 并 **阻止保存**。
3. 行表 **可为空**（无内容行）即可保存，**不要求至少 1 行**。

### H-4 保存后落位（P0）

**As** 资产管理员，**I want** 保存后的自定义卡片出现在 Assets，**so that** 与内置卡片一起管理。

**AC**

1. 新卡片排在 **内置卡片之后**（按创建顺序）。
2. 适用关联 Story **【卡片编辑】assests 卡片自定义**（#602，模块 G）的 **增删 / 固定位置 / 数据不丢** 规则。

### H-5 自定义卡片数量（P0）

**AC**

1. 自定义卡片允许添加 **多张**，上限 **10 张**。
