## 需求描述（Product Doc）

### 1. 订阅

- **Product Workspace（PW）** 订阅被引用到 **PW workspace** 中的 **SEMS 资产内容**的**状态变更信息**（**仅状态**）。
- 订阅方式不再沿用此前 PKI/KMS 的订阅模式（见 Out of Scope）。

### 2. 创建版本 / 批次时的 SE 状态校验（动作）

- 当被引用到资产中的 **SE profile** 通过**状态接口**查询为 **非 active**（SE 状态 / SEMS 状态）时，**无法创建版本和批次**。
- 失败提示（Product Doc 动作段落原文）：
  - 中文：**SE芯片状态变更，请检查SE profile状态**
  - 英文：**The status of the SE chip has changed. Please check the status of the SE profile.**

### 3. 验收标准（AC）

- **AC-05**：Product Workspace（PW）订阅被引用到 PW workspace 中的 SEMS 资产的状态变更信息。
- **AC-07**：创建版本和批次时，对资产中被引用的 SE profile **调用状态接口**查询其状态。
- **AC-08**：当查询到 SE profile 状态为**非 active**（SEMS 的状态）时，创建版本或批次**失败**。
- **AC-09**：创建版本或批次失败时给出提示：
  - 中文：**SE profile状态变更，请检查SE profile状态**
  - 英文：**The status of the SE profile has changed. Please check the status of the SE profile.**

## 评论 / 待确认

- **AC 编号缺口**：Product Doc 仅有 AC-05、AC-07～AC-09，**AC-06 缺失**，待产品确认是否为遗漏或合并。
- **失败提示文案不一致**：动作段落写「SE**芯片**状态变更」，AC-09 写「SE **profile**状态变更」，中英文均不一致，待产品确认以哪套为准。
- **订阅范围**：正文强调「只有状态」，待确认具体订阅哪些状态字段（如 active / deactive 等）及变更推送时机。
- **状态接口**：创建版本 / 批次时调用的 SEMS 状态接口规格（路径、参数、非 active 枚举值）待 Tech Doc 或接口文档补充。
- **UI 规格**：Product Doc 未嵌入参考图，失败提示的展示形式（Toast / Dialog / 行内错误）待 UI 或开发补充。
