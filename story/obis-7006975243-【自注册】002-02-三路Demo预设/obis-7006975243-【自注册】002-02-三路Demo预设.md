### 5. 交互行为

- 用户对预设过程无感知（注册成功后异步创建）
- **列表页**展示「Demo Data / 测试数据」标签（详情页不展示该标签，见评论修订）
- 用户可编辑 Demo 产品的非核心字段（Description 字段已去掉）
- 用户可删除 Demo 产品内的单个资源，删除后系统不重建
- 用户可删除整个 Demo 产品，删除后系统不重建

### 6. 命名与标识

- Demo 数据在列表展示 `Demo-` /「Demo Data / 测试数据」标签，不展示环境标签（Test / 正式环境等），仅标识为 Demo 数据
- 所有 Demo 资源不计入配额和用量统计

### 7. 异常处理

| 场景 | 处理方式 |
|------|----------|
| FM 调用超时 | TA 侧重试 3 次，间隔 30 秒 |
| Cloud Factory 创建成功，Station 创建失败 | 回滚已创建的 Factory，记为失败 |
| Vault 调用超时 | TA 侧重试 3 次，间隔 30 秒 |
| KMS 密钥创建成功，PKI 链创建失败 | 回滚已创建的 KMS 密钥，记为失败 |
| PKI 链创建中途失败 | 回滚已创建的 CA 证书，记为失败 |
| PM 调用超时 | TA 侧重试 3 次，间隔 30 秒 |
| Product 创建成功，资源包创建失败 | 回滚已创建的 Product，记为失败 |
| Product 和资源包创建成功，Version 创建失败 | 回滚已创建的 Product 和资源包，记为失败 |
| 重试 3 次均失败 | 记录该路预设结果为失败，不影响其他路的预设流程 |

### 8. 验收标准（来自 Description）

- AC-01: Factory 预设创建 1 个 Cloud Factory + 1 个 Programming Station，状态 Active
- AC-02: Vault 预设创建 1 个 KMS 密钥（AES128 TEST）+ 三层 PKI 证书链（PAA/PAI/DAC，Matter 规范，有效期 2 年）
- AC-03: Product 预设创建 1 个 Demo Product（Testing 环境，Matter 规范），含固件/Chip Config（Silicon Labs EFR32MG24）/Key 引用/证书引用/Matter Config + Draft Version
  - **评论修订**：Version 默认状态改为 **Approved**；Allowed Range Max=30、Default Duration=30；无 Description 字段
- AC-04: Demo 资源在列表展示 `Demo-` 标签，不展示环境标签，不计入配额和用量统计
- AC-05: 创建失败时按规则回滚已创建的资源
- AC-06: 用户可删除 Demo 资源，删除后不重建
- AC-07: 用户可编辑 Demo 产品的非核心字段
- AC-08: Demo 数据为每个租户独立创建，各租户的 Demo 数据互不共享
- AC-09: Demo 数据可被真实使用（如用预设密钥签发证书、用预设工厂创建批次），功能不做限制
- AC-10: Demo 数据支持编辑和删除，编辑/删除后的效果与用户自创建的资源一致
