## 需求描述（Product Doc）

> Product Doc 字段为「暂无」；以下内容整理自 Description 字段及评论补充。

### 1. User Story

作为免费版用户，我能从 Welcome 页面和个人信息页看到当前套餐名称/Package Name、免费版与企业版的对比入口，以及实时用量数据，建立配额心智和升级动机。

### 2. 版本对比入口

版本对比和升级引导有两个入口：

**入口 1：Welcome 页面顶部欢迎卡片**

- 欢迎卡片展示套餐名称/Package Name + 对比入口按钮
- 免费版：`Free Tier/免费版` 标签 + `Upgrade Plan/升级套餐` 链接
- 企业版：不展示

**入口 2：Profile 页面**

- 所属租户名称旁边展示套餐名称/Package Name
- 免费版标签可点击，进入版本对比详情
- 企业版标签不可点击

### 3. 版本对比详情

点击「Upgrade / 升级」或套餐名称/Package Name 后打开版本对比弹窗：

**① 顶部深色横幅**

- 标题：`OBIS Free Tier` / `OBIS 免费版`
- 描述（EN）：Full PKI + KMS capabilities with quota limits. No time limit, permanently free.
- 描述（ZH）：完整 PKI + KMS 安全能力，配额受限但功能完整。无时间限制，永久免费。

**② 对比表格区**

- 小标题：`Free Tier vs Enterprise` / `免费版 VS 企业版`
- 表头：`Feature / 功能项` | `Free Tier (Current) / 免费版（当前）` | `Enterprise / 企业版`

| 维度 / Dimension | 免费版 / Free Tier | 企业版 / Enterprise |
|------------------|--------------------|---------------------|
| 产品数量 / Products | 7 / 10 | Per contract / 按合同 |
| 单产品最大生产量 / Max Volume | ≤ 500 | Per contract / 按合同 |
| KMS 密钥数量 / KMS Keys | 3 / 5 | Per contract / 按合同 |
| KMS 密钥有效期 / KMS Validity | ≤ 2 years / 2 年 | Per contract / 按合同 |
| PKI 证书模板 / PKI Templates | 2 / 6 | Per contract / 按合同 |
| PKI 证书有效期 / PKI Validity | ≤ 2 years / 2 年 | Per contract / 按合同 |
| 工厂类型 / Factory Type | Cloud only / 仅云工厂 | Cloud + On-prem / 云 + 本地工厂 |

**③ 底部区域**

- 标题：`From evaluation to mass production` / `从评估走向量产`
- 描述（EN）：Upgrade to Enterprise with zero migration — all data retained.
- 描述（ZH）：升级企业版数据全保留、零迁移。
- 按钮：`Upgrade to Enterprise / 升级到企业版`（右侧箭头图标），点击打开联系销售弹窗（详见 FT-S-004-05）
- 免费版列展示实时用量值（Demo 中使用固定演示值）
- Demo 资源不计入限额统计
- 企业版列各展示绿色 ✓ 图标 + 「按合同」

### 4. 业务规则

- 用量数据统一服务聚合，计算逻辑统一
- Demo 资源不计入限额统计

### 5. 验收标准（来自 Description）

- AC-01: Welcome 页面欢迎卡片展示套餐名称/Package Name + 升级入口
- AC-02: Profile 页面所属租户旁展示套餐名称/Package Name，免费版可点击进入对比
- AC-03: 版本对比表含 7 项对比维度（产品数量/单产品最大生产量/KMS密钥数量/KMS密钥有效期/PKI证书模板/PKI证书有效期/工厂类型）
- AC-04: 免费版列展示实时用量值，Demo 资源不计入
- AC-05: 企业版列展示绿色 ✓ 图标 + 「按合同」
- AC-06: 对比面板底部有「升级到企业版」按钮
- AC-07: 点击「升级到企业版」按钮应打开联系销售弹窗
