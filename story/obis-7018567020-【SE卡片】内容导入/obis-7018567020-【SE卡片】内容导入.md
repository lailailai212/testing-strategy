## 需求描述（Product Doc）

### 1. 功能概述

- SE 卡片区域右上方提供「添加」按钮，用于从 SEMS 导入 SE 内容到 Assets。
- 只能添加一个 SE；若已添加，则「添加」按钮置灰不可再添加。

### 2. 添加按钮与下拉选择

- 点击「添加」按钮后，出现 **SE 下拉选择框**（单选）。
- 下拉选择框为单选，每次只能添加一个 SE。
- 当已添加 SE 后，「添加」按钮置灰，不可再次添加。

### 3. SEMS 列表查询

- 下拉选项内容由 **PW 调用 SEMS 接口**实时查询可用列表获得。
- **筛选条件**（须同时满足）：
  1. 与当前 **PV 环境**匹配（Test / Production）
  2. SE Profile 状态为 **Active**
  3. 操作者持有 **create authorization** 创建权限
- 下拉选项展示 SEMS 字段：**SE name**、**SE id**。

### 4. 验收标准（AC）

- **AC-01**：SE 卡片区域右上方提供「添加」按钮，点击后弹出 SE 下拉选择框。
- **AC-02**：下拉选择框为单选，每次只能添加一个 SE。
- **AC-03**：当已添加 SE 后，「添加」按钮置灰不可添加。
- **AC-04**：下拉选项内容由 PW 调用 SEMS 接口实时查询可用列表获得。
- **AC-05**：列表筛选条件须同时满足：① 与当前 PV 环境匹配（Test / Production）；② SE Profile 状态为 Active；③ 操作者持有 create authorization 创建权限。
- **AC-06**：下拉选项展示字段为：SE name、SE id。
