## 需求描述（Product Doc）

> Product Doc 字段为「暂无」；以下内容整理自 Description 字段及评论补充。

### 1. User Story

作为免费版用户，我希望能随时在页面底部看到快速入门、操作手册、FAQ 和工具下载入口，遇到问题时可查阅文档，降低使用门槛。

### 2. 顶部导航栏

- **面包屑导航**：当前页面路径指示
- **右侧操作区**：
  - **Docs / 文档中心**：链接跳转至外部文档站
    - 英文：`https://docs-sit.snowballtech.com/docs/obis`
    - 中文：`https://docs-sit.snowballtech.com/docs/zh-cn/obis`
    - 语言跟随系统设置自动切换
  - **Contact Us / 联系我们**（展示规则见 §6）
  - **全屏按钮**：切换全屏显示
  - **语言切换**：下拉菜单，支持 **English / 中文**

### 3. 工具栏模块（Welcome 页底部常驻）

Welcome 页面底部**常驻展示**四个模块卡片（**等宽网格布局**）：

| 模块 | 英文标题 | 中文标题 | 副标题（英/中） | 类型 | 说明 |
|------|----------|----------|-----------------|------|------|
| Quick Start | Quick Start | 快速入门 | Video walkthroughs & guides / 操作指引 | 外链文档 | 列表页 URL + 条目详情 URL |
| Operations Manual | Operations Manual | 操作手册 | Searchable documentation / 系统化文档与检索 | 外链文档 | 列表页 URL + 条目详情 URL |
| Tools & Downloads | Tools & Downloads | 工具下载 | CLI, SDKs, and utilities / 客户端 / SDK / 开发工具 | 内置工具卡片 | 工具卡片 + 下载按钮 |
| FAQ | FAQ | 常见问题 | Frequently asked questions / 高频疑问一键解答 | 外链文档 | 列表页 URL + 条目详情 URL |

每个卡片分为两部分：

- **卡片头部**：图标 + 大标题 + 副标题
- **列表部**：默认展示**最多 4 条**条目（标题）

> 各模块具体条目内容由产品上线前提供。

### 4. 外链跳转行为（Quick Start / Operations Manual / FAQ）

V1 中上述三个模块采用**外链**方式，**不内置 Drawer**：

| 交互 | 行为 |
|------|------|
| 点击卡片头部 | 浏览器**新标签页**打开该模块的**文档列表页** |
| 点击列表条目 | 浏览器**新标签页**打开该条目的**详情页** |

外链 URL 根据系统语言自动切换 EN / ZH 路径（见 AC-05）。

### 5. Tools & Downloads 交互（内置）

Tools & Downloads 为**内置工具卡片**（非外链）：

- **卡片头部**：点击打开**列表 Drawer**
- **列表条目**（卡片默认区 + Drawer 内）：工具名称 + 简介摘要 + **下载箭头按钮**；点击下载按钮**直接下载**，**无详情 Drawer**

**列表 Drawer 规则（仅 Tools & Downloads）：**

| 元素 | 规格 |
|------|------|
| 关闭 | 右上角 **关闭按钮**，点击关闭 Drawer |
| 标题 | **Tools & Downloads / 工具下载** |
| 内容 | 该模块下**全部**工具条目；每条：工具名称 + 简介摘要 + 下载箭头按钮 |
| 分页 | **不分页**，全部条目一次性展示 |

### 6. 联系我们入口

**展示规则（Description 原文）：**

- 顶部导航栏 **Contact Us / 联系我们** 按钮
- **仅当**该用户**所有租户均为未签约状态**时展示
- 用户属于**至少一个已签约租户**时，在**任何租户上下文**下均**不展示**

**交互（评论 2026-06-25 更新，优先于 Description 中的「联系销售弹窗」描述）：**

- 所有 **Contact Us / 联系我们** 入口统一为打开**外部链接（新窗口）**
- 中文：`https://www.snowballtech.com/zh/contact-us`
- 英文及所有其他语言：`https://www.snowballtech.com/contact-us`

### 7. 全局语言切换

- 顶部导航栏语言切换下拉（共 **2** 种语言）
- 切换后工具栏模块**标题、副标题、条目名称、Drawer 内容**及**外链 URL** 全部**即时切换**

## Story AC（Description 原文）

1.（AC-01）Welcome 页面底部常驻 4 个模块卡片（Quick Start / Operations Manual / Tools & Downloads / FAQ）

2.（AC-02）每个卡片分头部（图标 + 大标题 + 副标题）和列表部（最多 4 条条目，标题）

3.（AC-03）Quick Start / Operations Manual / FAQ 点击卡片头部，浏览器新标签页打开对应的文档列表页

4.（AC-04）Quick Start / Operations Manual / FAQ 点击列表条目，浏览器新标签页打开该条目的详情页

5.（AC-05）外链 URL 根据系统语言自动切换 EN/ZH 路径

6.（AC-06）Tools & Downloads 点击卡片头部打开列表 Drawer，展示所有工具条目（标题 + 简介 + 下载按钮）

7.（AC-07）Tools & Downloads 点击条目下载按钮直接下载，无详情 Drawer

8.（AC-08）语言切换后所有文案和 URL 即时切换

9.（AC-09）顶部导航栏展示「Docs / 文档中心」「Contact Us / 联系我们」、全屏按钮和语言选择器

10.（AC-10）「Contact Us / 联系我们」仅在所有租户均未签约时展示
