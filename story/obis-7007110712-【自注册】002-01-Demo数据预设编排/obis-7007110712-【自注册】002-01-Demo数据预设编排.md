### 1. User Story

作为免费版注册用户，我注册成功后系统自动为我创建 Demo 数据，我进入系统即可看到完整的云工厂、密钥、证书和产品样本，无需从零搭建，降低首次使用的空白态摩擦。

### 2. 触发条件

- 仅自注册 Tenant 触发预设
- 同一 Tenant 不重复触发（每个 Tenant 生命周期内仅执行一次）
- 运营后台开通的 Tenant 不触发预设

### 3. 编排流程

```text
注册成功 → Tenant 创建完成
                │
                ▼
        触发 Demo 预设任务（异步）
                │
        ┌───────┼───────┐
        ▼       ▼       ▼
     创建 FM  创建 Vault  创建 PM
     Demo     Demo KMS   产品 Demo
     Factory  Key +      数据
     + Station PKI 链   (Product +
                        Version +
                        固件等)
        │       │       │
        └───┬───┴───┬───┘
                ▼
        记录预设结果
        ┌────┴────┐
        ▼         ▼
    全部成功   部分失败 → 自动重试 3 次
```

### 4. 预设资源汇总

| 资源类型 | 触发条件 | 数量 | 创建模块 |
|----------|----------|------|----------|
| Cloud Factory + 烧录站 | 注册成功 | 1 Factory + 1 Station | FM |
| KMS 密钥 + PKI 三层证书链 | 注册成功 | 1 Key + 3 证书 | Vault |
| 产品 Demo 数据 | 注册成功 | 1 个产品 + 资源包 + Version | PM |

> 三路资源的字段规格与交互细节见关联 Story【自注册】002-02: 三路Demo预设 (#7006975243)。

### 5. 模块依赖与执行顺序（评论 2026-07-14 确认）

| # | 模块 | 链路内顺序 | 跨模块依赖 |
|---|------|------------|------------|
| 1 | KMS | 密钥 | 与 #2、#3 **互相独立**，一失败不影响其他模块 |
| 2 | PKI | 根证书 → 中间证书 → 叶子证书（上一级不成功，下一级不开始） | 与 #1、#3 **互相独立** |
| 3 | 工厂（FM） | 工厂 → 烧录站（上一级不成功，下一级不开始） | 与 #1、#2 **互相独立** |
| 4 | 产品（PM） | 产品 → 版本；**版本依赖 #1 与 #2**（KMS、PKI 不成功则版本不开始） | 版本依赖 KMS + PKI |

> **已删除 AC-02**（2026-07-08）：原「三路（FM/Vault/PM）独立并行、任一失败不影响其他」因模块依赖不再适用；跨模块关系以本表为准（KMS/PKI/工厂独立；产品版本依赖 KMS+PKI）。

### 6. 交互行为

- 用户对预设过程无感知（异步注册后触发）
- 预设资源在列表和详情页展示「Demo Data / 测试数据」标签
- 用户可删除 Demo 资源，删除后系统不重建

### 7. 异常处理

| 场景 | 处理方式 |
|------|----------|
| KMS / PKI / 工厂 任一失败 | 各自按链路重试；三者互相独立，一失败不影响其他模块数据 |
| 链路内上一级失败（如工厂未成、根证书未成） | 下一级不开始（烧录站 / 下一级证书不创建） |
| KMS 或 PKI 失败 | 产品**版本**不开始；工厂链路不受影响 |
| 产品 Demo 预设失败 | 按产品链路重试；不回滚已成功的 KMS / PKI / 工厂数据 |
| 用户删除某个 Demo 资源 | 系统不重建，不影响其他 Demo 资源 |
| 全部重试仍失败 | 记录预设结果为部分失败，通知运营人员，不阻塞用户 |

### 8. 验收标准（来自 Description，已按评论修订）

- AC-01: 自注册 Tenant 创建成功后异步触发 Demo 预设任务
- ~~AC-02: 三路（FM/Vault/PM）独立并行调用，任一模块失败不影响其他~~（**已删除**；依赖见 §5）
- AC-03: 每路失败自动重试 3 次（间隔 30 秒），全部失败不阻塞用户
- AC-04: 用户对预设过程完全无感知
- AC-05: Demo 资源展示「Demo Data」标签，用户可删除且系统不重建
- AC-06: 运营后台开通的 Tenant 不触发预设
- AC-07: 同一 Tenant 生命周期内仅触发一次
